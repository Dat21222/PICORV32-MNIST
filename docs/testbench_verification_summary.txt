2. SOC & MMIO MEMORY MAP REFERENCE
--------------------------------------------------------------------------------
- CPU BRAM (blk_mem_gen_0) : 0x0000_0000 - 0x0000_FFFF (64 KiB, 1-cycle read latency)
  * 0x0000_0000 - 0x0000_0FFF : RISC-V Firmware (.text, .rodata, .data, .bss)
  * 0x0000_1000 - 0x0000_130F : Image #0 (784 bytes)
  * 0x0000_1400 - 0x0000_170F : Image #1 (784 bytes, used in Test Case 2)
  * 0x0000_1800 - 0x0000_1B0F : Image #2 (784 bytes, used in Test Case 2)
  * 0x0000_2000 - 0x0000_200C : CPU Result & Completion Mailboxes
  * 0x0000_F000 - 0x0000_FFFF : CPU Stack (SP initialized to 0x0001_0000)

- MLP MMIO Registers (mmio_mlp_bao.v, Base = 0x1000_0000):
  * 0x1000_0000 (ADDR_CONTROL)     : bit[0] = acc_start, bit[1] = acc_clear
  * 0x1000_0004 (ADDR_STATUS)      : bit[0] = acc_busy, bit[1] = done_latched,
                                     bit[2] = can_accept_pixel, bit[3] = input_full
  * 0x1000_0008 (ADDR_PIXEL_DATA)  : bits[7:0] = unsigned 8-bit pixel (0..255)
  * 0x1000_000C (ADDR_PIXEL_COUNT) : Current loaded pixel count (0..784)
  * 0x1000_0010 (ADDR_RESULT)      : bits[3:0] = predicted digit class (0..9)

[Objective]
